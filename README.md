# gvac-images

Static image hosting for Grand Valley Adaptive Climbing email and social, served via GitHub Pages.

- `email/<year>/` — photos sized for email (1200px max width; two-up images 600px).
- `social/<year>/` — finished social graphics (1080px).
- `brand/` — logo, header, dividers.

URL pattern: `https://climbherm.github.io/gvac-images/email/2026/<file>.jpg`
(Add a CNAME for `img.gvadaptive.org` once DNS is set.)

Only use photos covered by a media release (see the media-release tracker).
